# 报告交付模板

1. 决策摘要：先验证哪些产品×市场×买方，为什么；反对证据与边界。
2. 卖方能力：已证实、自述、未知；角色与报价约束。
3. 产品/HS：版本、含量/用途、纳入排除、代理误差；原料与成品分线。
4. 数据：来源、年份与同比窗口、单位、流向、覆盖；失败/缺失与版权限制。
5. 规模/正增量/门槛正增速各前10/20，基数与实际数量；全球需求和中国出口分开。
6. 异常与竞争：量价、低基数、转口、来源结构、缺报，不填造全球总额。
7. OEM/ODM/trader/brand适配：买方路径、门槛、证据及当前角色优先级。
8. A/B/hold/watch与下一步：明示机械门槛和人工判断，无虚构评分。
9. 准入与到岸经济：现行规则来源和时间，未核的写待办，不猜税率。
10. 下游brief、待补资料、复算方法与文件。声明draft，用户选择后进入客户发现。

脚本的report.md仅为量化及分级底稿，分析员应补充以上叙述，并保留底稿、input-snapshot.json、rankings.json、records.csv和manifest.json。合成例不等于行业调研。
